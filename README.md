## 二、本仓的三个结论（先说结论，再看细节）

1. **原文 19 条技术声明里：9 条是错的，4 条半真，只有 2 条站得住。** 详见 `docs/CLAIM-LEDGER.md`。
2. **"10 轮沙盘全绿"是编的**：无命令 / 无 exit code / 无日志 / 无产物，表头写"预期"却判"结果绿"。
3. **真正值钱的不是四个战术，是四个观测方向**：上下文长度、数据/指令边界、副作用不可逆、隔离强度。我们把这四个方向做成了实验。

- 仅限**本地 VMware Host-Only 隔离靶场**，仅限**自有靶机与自有资产**。
